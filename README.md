# 📱 Calculadora de IMC — Android App

Este projeto consiste em um aplicativo Android nativo desenvolvido em **Kotlin**, com o objetivo de calcular o Índice de Massa Corporal (IMC) do usuário a partir das informações de peso e altura.

O aplicativo realiza o cálculo automaticamente, classifica o resultado de acordo com as faixas de IMC e apresenta o diagnóstico em uma segunda tela, proporcionando uma experiência simples e intuitiva.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em desenvolvimento Android, colocando em prática conceitos de programação, construção de interfaces e navegação entre telas.

## 🛠️ Tecnologias, componentes e ferramentas

### Linguagem e estrutura
- **Kotlin:** linguagem utilizada no desenvolvimento da aplicação.
- **XML:** criação e estruturação das interfaces Android.

### Componentes e layouts Android
- **Activity:** gerenciamento das telas da aplicação.
- **View:** estrutura base dos componentes visuais.
- **LinearLayout:** organização dos elementos em orientação vertical ou horizontal.
- **ConstraintLayout:** posicionamento e organização dos elementos da interface.
- **TextView:** exibição de textos.
- **EditText:** campos para entrada de dados do usuário.
- **Button:** botões para executar ações.
- **ImageView:** exibição de imagens.

### Navegação e interação
- **Intent:** comunicação e navegação entre Activities, com envio de informações entre telas.
- **Snackbar:** exibição de mensagens rápidas e feedback ao usuário.

### Ferramentas de desenvolvimento
- **Android Studio:** ambiente de desenvolvimento (IDE).
- **Android SDK:** ferramentas e recursos para desenvolvimento Android.
- **Git:** controle de versão.
- **GitHub:** hospedagem e gerenciamento do código-fonte.
